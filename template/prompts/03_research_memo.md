# Prompt 03: research memo

Before pasting: you have read at least one literature note against its PDF and corrected what was wrong.

---

Write a one-page research memo in `notes/research_memo.md`, using only `README.md` and the notes in `notes/literature/`.

Structure, with these headings:

1. **Question.** One paragraph.
2. **What we know.** What the literature notes establish, with the note each point comes from, in the form `(see notes/literature/<file>.md)`.
3. **What we don't know.** The gap this project targets.
4. **Design.** How we would answer the question: data, unit of analysis, comparison. Use what is in `README.md`; where `README.md` is silent, write "to decide" rather than filling the gap yourself.
5. **Risks.** Three things that could make the project fail.

Rules: one page, about 500 words. No claim about a paper that is not in a literature note. No references to papers that are not in `literature/`. If you think a key paper is missing, say so in one line at the end, with the author and year, marked "suggestion, not read".
