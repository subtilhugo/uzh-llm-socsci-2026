# Project history

Newest entry first. One entry per working session. The agent writes it; you read it before
accepting it. This file is the project's memory: a fresh agent session should be able to
answer "where does this project stand?" from this file alone.

Template for an entry:

## YYYY-MM-DD

**Done.** What was produced (files).

**Decided.** Choices made and why.

**Verified by a human.** What a person actually checked, against what.

**Open.** What is unresolved, what the next session should start with.
